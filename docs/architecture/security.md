# 安全与信任边界

## 信任边界

信任本地用户、已授权宿主、锁定依赖及随发行物交付且显式注册的 Built-in Capability。
不信任 MCP 参数、数学表达式、文件名、附件、项目内手工修改、重解析点和中断遗留状态。
C1 worker 不获得 SQLite、项目根、MCP 上下文或任意输出路径。

## 有限输入与输出

| 边界 | 限制 |
|---|---|
| MCP 请求 | 1 MiB |
| 内联响应 | 256 KiB；更大结果使用制品摘要 |
| 单 Attempt | 最多 16 个 Artifact、合计 64 MiB |
| Built-in Capability | 默认 10 秒、最大 60 秒协作式 deadline |

M1 常规能力在进程内协作检查单调时钟，不能声称通用硬超时。C1 只为批准的竞赛能力使用
60 秒短生命周期 worker；不自动重试数学执行，也不形成 worker 池。

## 路径、锁与持久化

所有用户路径在项目根约束内解析，拒绝不可信绝对路径、越界、符号链接或 junction 等重解析点。
只允许受管 `.modeling/` 拥有者替换受管文件。单写者锁覆盖恢复和写事务；doctor 使用独立只读快照，
不获取写所有权、不修复、不迁移。

## 协议与秘密

MCP STDOUT 只能包含协议帧；日志和有限诊断写 STDERR。公开错误、诊断、测试和证据不得包含绝对路径、
环境秘密、原始异常、任意项目内容或无限输出。所有边界 DTO 严格验证并拒绝未知字段。

稳定错误语义见[MCP tools v1](../contracts/mcp-tools-v1.md)，操作恢复见[恢复手册](../operations/recovery.md)。
