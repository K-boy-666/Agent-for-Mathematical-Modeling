# modeling_infrastructure 目录规则

本文件补充[根规则](../../AGENTS.md)，作用域仅限 `modeling_infrastructure`。

- 本层拥有 SQLite、项目路径、锁、原子发布和恢复适配。
- 所有权威写入只发生在绑定后的项目 `.modeling/` 根内。
- 路径必须拒绝越界、重解析点、不可信绝对路径和非普通文件。
- 数据库引用制品前必须先完成制品发布；恢复只收敛本层拥有的状态。
- `doctor` 的源项目路径保持只读；诊断快照不得复用写入连接或项目锁。
- SQLite、文件系统和外部进程测试使用真实临时边界，不在仓库根留状态。
- 不向核心泄漏 SQLite 类型、绝对路径、原始异常或宿主信息。
