# modeling_bootstrap 目录规则

本文件补充[根规则](../../AGENTS.md)，作用域仅限 `modeling_bootstrap`。

- `composition.py` 是具体能力、基础设施、MCP 与核心相遇的唯一组合根。
- Built-in Capability 与 Validator 在组合时显式构造、注册并一次性封存。
- 组合根只负责装配和生命周期，不实现数学、业务规则、SQL 或协议映射。
- 新依赖先确认已有端口与抽象预算；不得引入服务定位器或动态发现。
- 构造应无副作用；启动、恢复、关闭必须保持清晰且可测试的拥有关系。
- 组合测试应证明依赖方向和具体注册，不复制实现内部细节。
