# tests 目录规则

本文件只补充根规则，作用域是 `tests`。

- 测试名称说明它防止的具体回归。
- 先观察 RED，再写最小 GREEN。
- 优先真实组件、真实 SQLite、真实文件和真实 STDIO 子进程。
- 项目状态只写入 `tmp_path` 或 Harness 临时目录。
- 时间边界使用可控时钟；禁止依赖长时间 sleep。
- 预期值使用手工字面量，不从被测实现推导。
- 必需测试不得 skip；不要用重试隐藏不稳定。
- 安全、架构、契约和复现测试留在对应测试分组。
- A12.3 只固定 context 与 package inventory，不实现 A12.4 验收策略。
- 测试专用 helper 留在测试代码，不污染生产接口。
